# KINETIC · Blood Orange Sparkling Energy

A luxury beverage showcase featuring real-time 3D WebGL product visualization, smooth scroll choreography, and responsive editorial layout.

Built with React 19, Three.js, React Three Fiber, GSAP, and Tailwind CSS.

## Overview

- **Authentic PBR Visualization**: Renders the authentic silver brushed aluminum beverage can with its bold blood-orange solar disc and sharp typography.
- **Scroll Choreography**: 4-beat narrative flow driven by GSAP Observer and smooth camera waypoints.
- **Clean Editorial Design**: Minimalist layout with calibrated typography, ample negative space, and zero spatial overlap across all viewports.
- **Responsive Architecture**: Split-screen narrative on desktop and pinned vertical stage on mobile.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D / WebGL**: Three.js, @react-three/fiber, @react-three/drei
- **Motion**: GSAP + @gsap/react
- **Styling**: Tailwind CSS v4

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Local Preview

```bash
npm run preview
```

### Verification & Testing

```bash
# Run headless visual audit in Chromium
npm run audit

# Run full 4-tier E2E verification suite
npm run test:e2e
```
